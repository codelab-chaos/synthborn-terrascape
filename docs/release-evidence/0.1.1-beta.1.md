## Live Console Permission Matrix

One temporary validation token was bound to the existing Gigantomancer UUID while the
player was offline. The token's scope did not change during the matrix, so each result
demonstrated current Hytale permission lookup rather than token-carried command authority.

- Offline Admin: `/terrascape status` succeeded and returned private command output.
- Ordinary player with only `terrascape.map.use`: text chat succeeded; `/terrascape
  status` and `/kick Nobody` were denied.
- Moderator with `hytale.system.command.kick`: `/kick Nobody` reached normal argument
  validation (`No such player`) while unrelated Terrascape admin commands remained denied.
- Restored Admin group: `/terrascape status` succeeded again; direct validation
  permissions were removed and the original permissions file matched its backup.
- Live browser E2E mounted the console from the identity-bound link and read private
  history.

No game client was connected during this validation window. The online
`PlayerChatEvent` path therefore remains unit/integration tested but was not claimed as a
live online-player check.

## Cache And Rendering Evidence

Focused Chromium measurements against the dedicated server:

- Terrain radius 4, cosmetics off: cold load 7,936 ms; all 81 terrain records persisted
  within another 499 ms; warm load 6,838 ms with 81/81 IndexedDB hits, zero terrain HTTP
  requests, zero failures, and no page errors.
- Map-tile radius 4: cold load 3,925 ms with 81 HTTP requests; warm load 1,016 ms with
  81/81 local cache reuse, zero tile HTTP requests, no pending/in-flight/promoting work,
  and no page errors.

The broad default radius-16 map horizon represents up to 1,089 separately textured mesh
draw calls. The full SwiftShader smoke was stopped after frame gaps escalated from roughly
150 ms to multiple seconds as hundreds of meshes accumulated. Acquisition remained
bounded and responsive at the component radius; this is dispositioned as the known
per-tile representation limit, with atlas/instanced rendering tracked post-alpha. It is
not recorded as a passing full-horizon performance gate.

continued beta validation. Public CurseForge submission remains conditional on the
