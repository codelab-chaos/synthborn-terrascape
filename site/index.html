Terrascape Quick Start

Install and check

For a map used only on the server computer, this is all you need.

  1. Download the latest jar from CurseForge.
  2. Stop the server and place Terrascape-<version>.jar in <save>/mods/.
  3. Start the server. The log shows Terrascape started.
  4. On the server computer, open 127.0.0.1:5960. Your map loads.

Share it with players

Stop the server, edit one file, restart.

1

Choose who can view

public default
Anyone who can reach the web port. Fine for local or LAN maps, or an open map.
restricted
Only visitors with a personal link. Use it for any private, internet-facing map.

With restricted, give the permission to a group or a player. They then run /terrascape maplink in-game:

/perm group <group> add terrascape.map.use
/perm user <player> add terrascape.map.use

The firewall decides who can connect. access.mode decides whether those visitors need a link.

2

Open it to your network

The map listens on 127.0.0.1, the server computer only. Set http.host=0.0.0.0 to listen on every network interface, and set http.port to the port your host assigns. Then:

  • Allow that TCP port through the firewall and any hosting panel.
  • Behind a home router, forward the port to the server computer.
  • On a hosted server, ask for an extra TCP port. The game port can't carry map traffic.

Using a reverse proxy on the same machine? Keep http.host=127.0.0.1 and point the proxy at it. RCON (port 25578) is off by default, isn't needed for the map, and should never be public.

3

Set the address players use

Without it, generated links can come out as 0.0.0.0, localhost, or a raw IP. Include the port when visitors have to type it, or use https://map.example.com behind an HTTPS proxy.

This only changes generated links. DNS, HTTPS, and the firewall are set up separately.

4

Choose how long links last

Personal links expire after the set number of hours, from 1 to 8760 (a year). Admin links carry admin web access, so keep them short. When the viewer shows map access expired, the player needs a new link.

✓

Restart and test as a player

  1. Restart the server to apply the file.
  2. Grant terrascape.map.use to whoever needs access.
  3. Run /terrascape maplink in-game and open the link from a player's computer.
  4. The map loads and the link uses your public address. If not, see Troubleshooting.
# 1 Who can view (default: public)
access.mode=restricted
# 2 Network (default host: 127.0.0.1)
http.host=0.0.0.0
http.port=5960
# 3 Address used in generated links
access.publicBaseUrl=http://map.example.com:5960
# 4 Link lifetime in hours
access.mapTokenTtlHours=24
access.adminMapTokenTtlHours=4

Terrascape creates this file on first start. Find the active path with /terrascape status or the log line Terrascape config loaded from.

Permissions

terrascape.map.use
/terrascape and personal map links.
terrascape.admin
Admin subcommands and admin links. Trusted staff only. A custom admin group needs both nodes.

Removing a permission doesn't cancel links already made. Revoke the player's Link ID from /terrascape tokens. To cancel every link, stop the server, delete access-tokens.json, and start it again.

Other settings

Limit visible worlds
worlds.allowlist=world1,world2. Blank (the default) shows every loaded world.
Web chat console
Personal links open a chat and command panel with T, using the player's own permissions. Anonymous visitors never get it. Turn it off with features.webConsole=false.
Server load
server-config.json in the same folder caps what viewers may request: stream radius, map-tile radius, load concurrency, and update rates. Lower these first if the server works too hard.
Remote or headless server sign-in
Run /auth login device, complete the printed URL and code, and check with /auth status. This is Hytale's sign-in and is separate from map links.
