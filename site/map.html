Using the Terrascape Map

Open your server's live 3D map, fly around the world, and follow other players.

Open the map Server setup

Open the map

  • Open the map address your server admin gives you, for example http://your-server:5960.
  • If the map needs a personal link, it ends in a secret key (…?key=abc123). Opening it signs you in for this browser and removes the key from the address bar.
  • When a map access expired notice appears, ask an admin for a new link, or run /terrascape maplink in-game if you have access.

Treat a personal link like a password until it expires.

Follow players

Each player in the Players list on the right has quick actions:

  • Click the tile to fly the camera to that player.
  • Eye view shows the world through that player's eyes.
  • Follow trails the player from an overhead angled camera.

Settings panel

Click the gear icon (top right) to open the panel. Controls are grouped into collapsible World, Render, and Experimental sections. A few live in the title bar: the Mobs and Mob Blocks toggles, the mob update rate, and Sync Time (use the world's time for lighting).

World
  • World: pick which world to view. Switching reloads terrain and markers.
  • Voxel Mesh Distance: how far 3D terrain loads around you (0 to 12).
  • Players / Auto / Bounds / Mob Blocks: show player markers, load terrain around the camera automatically, show chunk boundaries, and show mob headshot blocks on the ground.
  • Clear Browser Cache: removes terrain and map tiles stored in this browser only. The server and other players are not affected.
Render
  • Map Tiles: the flat 2D map under the terrain, with distance and loading sliders.
  • Shade: soft shadow shading, with size and darkness, plus tree shade.
  • Land motion: chunks rise into place as they load.
  • Water: Solid, Transparent, or Hidden.
  • Cosmetic Blocks (Off / Baked / Split) and Visual Detail (Basic / Struct / Foliage): how much decorative detail to load.
Experimental
  • Fog: distance fog with near, far, strength, and haze sliders.

Read the map

  • The sky ribbon (top center) shows the world's current time and phase.
  • The Render Details card (bottom right) shows status, loaded chunks, mob count, and your camera position. Click its header to collapse it.

Web chat console

A personal link from /terrascape maplink also lets you use the web console. Press T while the map has focus, type to chat, or start with / to run a command. Press Esc to close it.

The link does not make you an operator. Commands use your own Hytale permissions. Visitors without a personal link don't get the console, even on a public map.
